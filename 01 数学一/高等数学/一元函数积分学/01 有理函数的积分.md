## 四次因式分解套路总结

### 一、适用类型

对于只含偶次幂的四次多项式：

```plain
x⁴ + bx² + 1
```

特点：

1. 不含 x³ 项和 x 项。
2. 最高次项为 x⁴，常数项为 1。
3. 可以优先考虑构造两个对称的二次因式。

### 二、方法一：对称因式待定系数法（优先推荐）

设：

```plain
x⁴ + bx² + 1
= (x² + ax + 1)(x² - ax + 1)
```

展开：

```plain
= (x² + 1)² - a²x²
= x⁴ + (2 - a²)x² + 1
```

比较系数：

```plain
2 - a² = b
```

得到：

```plain
a² = 2 - b
```

当 b ≤ 2 时：

```plain
a = √(2 - b)
```

因此：

```plain
x⁴ + bx² + 1
= (x² + √(2-b)x + 1)(x² - √(2-b)x + 1)
```


### 三、方法二：加减凑项法（平方差公式）

观察：

```plain
(x² + 1)² = x⁴ + 2x² + 1
```

因此：

```plain
x⁴ + bx² + 1
= x⁴ + 2x² + 1 - (2-b)x²
= (x² + 1)² - (2-b)x²
```

当 b ≤ 2 时，利用平方差公式：

```plain
A² - B² = (A+B)(A-B)
```

得到：

```plain
x⁴ + bx² + 1
= (x² + 1 + √(2-b)x)(x² + 1 - √(2-b)x)
```


### 四、例题：分解 x⁴ - x² + 1

方法一：待定系数法

```plain
x⁴ - x² + 1
= (x² + ax + 1)(x² - ax + 1)
```

展开：

```plain
= x⁴ + (2-a²)x² + 1
```

比较系数：

```plain
2 - a² = -1
a² = 3
a = √3
```

最终：

```plain
x⁴ - x² + 1
= (x² + √3x + 1)(x² - √3x + 1)
```

方法二：加减凑项法

```plain
x⁴ - x² + 1
= x⁴ + 2x² + 1 - 3x²
= (x² + 1)² - (√3x)²
= (x² + 1 + √3x)(x² + 1 - √3x)
```


### 五、拓展：当 b > 2 时怎么办？

前面的对称形式：

```plain
(x² + ax + 1)(x² - ax + 1)
```

要求：

```plain
a² = 2 - b ≥ 0
```

因此，当 b > 2 时，不能使用这一形式进行实系数分解。

此时可以换一种思路：

```plain
x⁴ + bx² + 1
= (x² + A)(x² + B)
```

展开：

```plain
= x⁴ + (A+B)x² + AB
```

比较系数：

```plain
A+B = b
AB = 1
```

因此 A、B 是方程

```plain
t² - bt + 1 = 0
```

的两个根：

```plain
A = (b + √(b²-4))/2
B = (b - √(b²-4))/2
```

当 b ≥ 2 时，可以直接得到实系数分解。

### 六、解题策略总结

遇到 x⁴ + bx² + 1：

第一步：检查是否只有偶次幂。

第二步：根据 x² 项的系数选择方法。

```plain
b ≤ 2：
    优先构造 (x²+1)² - (2-b)x²
    使用平方差公式分解。

b ≥ 2：
    优先将 x² 看作整体。
    设 (x²+A)(x²+B)，比较系数。
```

第三步：如果不容易观察出凑项关系，  
        使用待定系数法，避免反复猜测。

核心口诀：

```plain
只有偶次，优先对称；
首尾为一，中间配方；
系数偏小，凑成平方差；
系数偏大，视作二次式。
```

注意：  
上述套路针对 x⁴ + bx² + 1。  
对于一般形式 x⁴ + bx² + c，  
需要根据常数项 c 调整因式结构。
