# 计算机组成原理 · 中断类指令

## 一、软中断指令

1. **定义**  
软中断指令是CPU指令集中的一类特殊指令，由**软件主动执行**，无需外部硬件设备发送中断请求，通过程序主动触发中断，属于**自愿中断（程序性中断）**。
2. **核心特征**
+ 触发方式：由代码主动调用，执行时机完全可控，无硬件随机性；
+ 产生来源：CPU内部指令执行，属于内部中断，与外设无关；
+ 运行特性：不受CPU开中断、关中断状态约束。
3. **核心作用**  
实现用户态向内核态的特权切换、系统调用、程序调试、异常陷入与底层系统服务调用。
4. **本质区分**  
硬中断：外设硬件异步随机发起，为强迫中断；  
软中断：程序指令同步主动触发，为自愿中断。

---

## 二、开中断指令 & 关中断指令

二者均为**CPU特权指令**，通过修改CPU内部**中断允许触发器（IF）**，全局管控**可屏蔽外部硬中断**。

### 1. 关中断指令

+ 硬件操作：中断允许触发器置 `0`；
+ 核心功能：禁止CPU响应所有**可屏蔽外部硬中断**；
+ 限制范围：仅屏蔽可屏蔽硬中断；
+ 不受影响：不可屏蔽中断（NMI）、软中断指令、运算异常等仍可正常触发；
+ 主要用途：保护临界区代码、完成中断现场保护与恢复、防止中断嵌套冲突。

### 2. 开中断指令

+ 硬件操作：中断允许触发器置 `1`；
+ 核心功能：恢复CPU对可屏蔽硬中断的响应能力；
+ 主要用途：临界区执行结束、中断服务程序收尾，恢复外设正常I/O中断响应。

### 3. 易混辨析

+ 开/关中断：**CPU全局级**控制，统一管理全部可屏蔽硬中断；
+ 中断屏蔽字：**设备局部级**控制，可单独屏蔽某一个指定中断源。

---

## 三、开中断、关中断与软中断的核心关系

1. **核心定论（高频考点）**  
开中断、关中断**只管控可屏蔽硬中断**，**完全不能屏蔽和限制软中断**。
2. **管控边界**
+ 开/关中断：是**外部硬中断总开关**，仅针对外设异步硬件中断请求；
+ 软中断：属于程序主动发起的内部陷入，不经过该硬件开关，独立生效。
3. **实际运行规则**  
CPU关中断期间，键盘、磁盘、网卡等所有可屏蔽硬中断都会被阻塞；  
但只要执行软中断指令，会立即触发中断，不受关中断影响。
4. **嵌套特性**  
CPU响应硬中断时，硬件会自动关中断以避免嵌套；  
但在硬中断服务程序内部，依然可以正常执行软中断指令。

---

## 四、极简背诵总结

1. 软中断：指令主动触发的内部自愿中断，**不受开/关中断控制**；
2. 开/关中断：特权指令，操作中断允许触发器，**仅管理可屏蔽硬中断**；
3. 软硬隔离：硬中断受全局开关约束，软中断独立运行、不可被全局屏蔽。
